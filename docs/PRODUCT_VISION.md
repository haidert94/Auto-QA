# Visión de producto — AutoQA
## Propuesta de valor
SaaS de QA web asistido por IA, pensado para equipos técnicos y no técnicos. El cliente registra una aplicación autorizada (pública o privada), entrega requisitos/documentación, configura roles y datos de prueba, y recibe pruebas automatizadas Playwright reutilizables, evidencias, hallazgos y un diagnóstico de calidad explicable.

## Diferenciación
- Experiencia en español; configuración guiada.
- Sin tokens/créditos visibles; suscripción por aplicaciones y capacidad, con límites transparentes de concurrencia, frecuencia, duración y uso razonable.
- IA híbrida: reglas y Playwright primero, modelo local para tareas aptas, API externa para razonamiento complejo. Escalado medido por calidad/costo.
- Pruebas persistentes y regeneración selectiva ante cambios.
- Trazabilidad entre requisitos, escenarios, pruebas, resultados y evidencia.
- Diagnóstico de documentación faltante, cobertura y riesgos; no prometer ausencia de defectos.

## Usuarios
Administrador del cliente, QA/ingeniero, responsable funcional/product owner y lector de reportes. Multiempresa (tenant) con aislamiento estricto antes de lanzamiento comercial.

## Alcance MVP
Registro seguro de proyectos/entornos; recepción de documentación; extracción de requisitos; IPA; exploración controlada de flujos simples; generación y ejecución Playwright; ICSP y reporte básico. Fuera del MVP: exploración autónoma irrestricta, garantía de cobertura completa, ejecución destructiva, SSO empresarial generalizado y facturación de producción.
